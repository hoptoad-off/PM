# Прототип «Закуп · Шох» — как открыть

`zakup-shoh.dc.html` — живой интерактивный прототип экранов Шоха. Это turn 3 из
общего макета `ui_solid1` («Финансы дня»), вырезанный в отдельный файл: здесь
только экраны закупа, без финансовых экранов бухгалтера и основателя.

## Как открыть

Файл подтягивает React с `unpkg.com`, поэтому **нужен интернет** — просто открыть
его двойным кликом из файловой системы недостаточно, нужен локальный сервер:

```
cd Products/retro-villain/Tasks/assets/T-007
python3 -m http.server 8000
```

Дальше открыть `http://localhost:8000/zakup-shoh.dc.html` в браузере.

## Файлы

| Файл | Что это |
|---|---|
| `zakup-shoh.dc.html` | Сам прототип — 7 экранов |
| `support.js` | Рантайм design-doc: `<sc-for>`, `<sc-if>`, `<x-import>` |
| `ios-frame.jsx` | Компонент `IOSDevice` — рамка телефона вокруг экранов |

Все три файла должны лежать рядом, прототип ссылается на них относительными путями.

## Важно

Прототип — **источник правды по составу экранов и поведению**, но не по пиксельным
значениям: это дизайн-комп, а не экспорт из Figma. Цвета, шрифты и отступы
согласуй с тем, что уже используется в retro-villain.
